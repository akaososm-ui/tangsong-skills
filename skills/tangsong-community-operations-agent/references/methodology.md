# 社群运营方法论（判断工具层）

本文件供技能在用户询问"底层逻辑 / 为什么 / 讲课材料"时读取。
这里只放**判断工具**，不放概念堆砌。每条都能拿来做判断。

---

## 1. 底层：社群为什么能卖货

### 1.1 两条购买路径

```text
交易思维：知道 → 熟悉 → 信任 → 购买
社交思维：需要 → 关注 → 信任 → 购买 → 持续购买
```

第一条路径上，用户面对的是**品牌和产品**。
第二条路径上，用户面对的是**一个人**。

社群的位置在这两条路径的中间：它是目前**批量建立信任成本最低**的场域。

**判断标准**：社群的目标不是"把人聚起来"，而是"让一群人开始信任你"。任何降低信任的动作，都不值得换一次转化。

### 1.2 你该先影响谁：三层圈层

| 圈层 | 是谁 | 特征 | 要做的事 |
|---|---|---|---|
| 核心层 | 铁杆用户，人数不宜多 | 有功能需求 + 情感需求，愿意花钱 | 深度服务，一对一 |
| 影响层 | 你的 KOL | 有专业度、有影响力、爱尝鲜、爱分享 | 请进来、给流量、给支持 |
| 外围层 | 围观和犹豫的人 | 还没有动作 | 找出来、晒出来、传出去、引回来 |

**配套数字**：1000 个铁杆粉丝，足够让一个人活得不差。
**判断标准**：不需要一万人的群，需要一个能真正影响 100—1000 个人的场。

### 1.3 算账要算终身价值

不要看单次成交，要看一个用户在他整个关系周期里能带来多少收益。
**判断标准**：获客成本的上限，由终身价值反推，不是由当次客单价反推。

## 2. 社群模型

```text
社群 = 一个持续供给「内容 · 关系 · 情绪」的系统
      用来完成「筛选人 → 建立信任 → 完成变现」的闭环
```

| 动能 | 负责什么 | 供给方式 |
|---|---|---|
| 内容 | 活力、吸引力、交付 | 稳定输出、外部嘉宾、内容工具 |
| 关系 | 留存、离开成本 | 项目协作、线下活动、多维度身份标签 |
| 情绪 | 忠诚、口碑、终身价值 | 可晒的成果、荣誉、榜单、仪式 |

**判断标准**：

- 群里没人说话时，先问"三种动能里我只供给了哪一种"。
- 让用户选一个**主供给**。三个都想要，通常意味着三个都做不到 80 分。

## 3. 三大机制

### 3.1 规则：规则的功能是筛人，不是管人

你写一条规则，就等于告诉一批人"这里不欢迎你"。留下来的，才是你真正想要的人。

**判断标准**：规则里必须**先有激励，后有禁止**。只有禁止的规则，不会被遵守。

### 3.2 角色：一个组织最少三个角色

只有群主一个人的社群，群主一停，群就停。

**判断标准**：能不能设想出"你三天不在，这个群也能转"的画面。设想不到，就是结构过度依赖一个人。

一人公司可以用志愿者角色解决：一位管理员 + 两位活跃用户。

### 3.3 活动：管峰值，也管习惯

- 定期活动（讲座、试用、晒图、邀请有奖）负责**养成习惯**
- 不定期活动（趣味玩法、惊喜促销）负责**制造峰值**

**判断标准**：用户对一段体验的记忆由峰值和终值决定。所以要刻意制造惊喜，而不是平均用力。

## 4. 群分层与精力分配

这是整套方法里最实用的一张表。

| 层级 | 门槛 | 精力投入 | 时效 |
|---|---|---|---|
| 鱼塘群 | 免费、无门槛，只管圈人 | **15%** | 约 1 周 |
| 中转群 | 需要完成一个低价动作 | **20%** | 2—4 周 |
| 核心群 | 付费或满足门槛才进得来 | **65%** | 3 个月—2 年 |

**判断标准**：**65%**。大多数社群失败，是因为把精力平均分给了所有人。

分层不是设计出来的，是长出来的。顺序通常是：综合群 → 发现诉求分化 → 按类目分群 → 按区域分群。

## 5. 用户分层

| 维度 | 内容 | 用途 |
|---|---|---|
| 身份属性 | 用户在社群里的角色：普通成员 / KOL / 合伙人 / 运营 / 群主 | 按对社群的贡献度划分 |
| 行为属性 | 购买行为，用最近购买时间、购买频率、购买金额三个指标 | 判断活跃度与贡献 |
| 自然属性 | 年龄、性别、地域、职业 | 帮同频的人互相连接 |

**判断标准**：标签越细，越容易找到同频的人，而同频是关系建立的基础。

## 6. KOL 运营

### 6.1 谁能算 KOL

能输出专业观点；能帮成员解决具体问题；能影响成员消费；对社群忠诚，能帮群主分担运营。

### 6.2 两条来源

- **外部邀请**：判断标准是有基础影响力、有专业背书、有完整项目经验。
  社交的价值在利益交换——要让人看到你的势能（你的圈子多少人、你能给他什么）。
- **内部培养**：筛选 → 进阶 → 实操 → 复盘。先通过任务找备选（有实操经验、表达有条理、反馈快），再给"加餐"，最后让他们把复盘分享出来。

### 6.3 与 KOL 的关系：筛选、赋能、驱动

**关键判断**：不要试图用规则去限制 KOL 的能量。

正确的做法是创建一套**能驱动 KOL 和你一起获利的协作方式**：

```text
把流量分给合伙人 → 合伙人成交用户 → 用户回到你的场域做复盘分享
→ 你用这些新内容做展示，吸引更多人加入
```

**判断标准**：你一个人挖掘不完社群用户的价值。既然挖不完，就让 KOL 帮你一起挖，然后让价值回流。

## 7. 变现与定价

### 7.1 五种变现方式

付费会员 / 社群卖货 / 会员的增值付费（训练营、咨询、陪跑）/ 资源对接 / 后端产品转化

**判断标准**：**先回答"钱从哪来"，再回答"群怎么活跃"**。顺序反了，最后会做成一个很热闹但不赚钱的群。

### 7.2 定价的三条判断

| 情况 | 判断 |
|---|---|
| 小众领域、专业性强 | 一上来定高价。用户注定不多，定价低了你赚不到钱，会降低服务动力 |
| 大赛道、团队小 | 定中等价位。定太高，用户预期过高，人数上来后服务跟不上，满意度下降 |
| 团队规模大 | 可以提高价格。运营能力能提升服务细节，这是裂变和续费的关键 |

**冷启动**：新社群没内容没人，就定低价，达到人数后阶梯上调。这个阶段靠内容输出和人脉链接补价值和社交价值。种子用户要给足荣誉感。

**停止涨价的信号**：当价格接近目标用户的支付能力上限时，就不要再涨。定位不变，用户画像就不变，支付能力不会因为你的内容变多而上升。

### 7.3 价格会决定三件事

1. **交付时间**：价格越高，服务周期越长
2. **产品功能**：按价格区分产品线，决定提供多少服务
3. **用户质量**：价格越低，整体素质、认同度、购买力都越低

**判断标准**：哪怕只收很低的价格，质量也明显好于完全不收费。价格是最重要的筛选工具之一。

## 8. 续费与留存

三种价值持续供给：

| 价值 | 怎么做 |
|---|---|
| 使用价值 | 定期行动营（必须是双向互动，不是单向分享）；提供内容工具、模板、资料、SOP |
| 社交价值 | 给互不相识的人一个合作项目；线下链接 |
| 情绪价值 | 好玩（可产生情绪的事件和玩法）；可晒（海报、证书、奖杯、徽章） |

### 关系密度

关系密度 = 成员之间互相认识的程度。

一个人只认识你，退出时失去 1 个连接。
一个人认识 5 个人，退出时失去 5 个连接。

**判断标准**：密度越高，离开成本越高，续费率越高。

提高密度的三个动作：多维度身份标签、社群项目协作、线下活动（一定要提前设主题，没主题的活动就是闲聊）。

### 成功的社群怎么定义

**群主可以抽身出去，社群依旧能够自我运营。**

## 9. 常见死法

### 9.1 蒸发式冷却

大量新成员涌入 → 高质量老成员觉得平均水平下降 → 离开或静默 → 社群水平进一步下降 → 恶性循环。

**解法**：阶段性调整 KOL 和普通成员的比例；为不同阶段的成员建立发声渠道；给"给予者"建立回报机制；定期答疑帮新人成长。

### 9.2 群被折叠

用户折叠而不退群，通常是因为：大部分时间闲聊但偶尔有好东西；聊天质量不高；付费群内容变差但不想退；发单太多但常有优惠。

**解法**：把内容分享的时间和频率固定下来；减少信息噪音；优先小群。

### 9.3 信息噪音

一切分享优先文字；一次表达完整信息；不自作主张发广告；点对点沟通走私聊；不要发零碎红包（保证单个金额）；问问题直接 @ 对方；不要频繁 @所有人；高质量信息沉淀到独立平台。

### 9.4 只有群主在输出

表现：群主的势能越来越强，社群的势能没有变化。

**判断标准**：用户记住的是"你很厉害"，不是"这个社群很厉害"。要让成员看到**社群在生产内容**，而不是看到**你一个人很厉害**。

## 10. 什么时候不该做社群

- 还没有任何一个真实交付过的用户
- 说不出"钱从哪来"
- 过去三个月没有稳定输出过内容
- 想法是"先建个群，以后再想"
- 打算靠一个群解决获客问题

**替代方案**：先做一对一、先做一次小型线下活动、先攒前 20 个真实用户、先把内容输出稳定下来。

**判断标准**：不做社群不丢人。用三个月做一个死群，才丢人。
