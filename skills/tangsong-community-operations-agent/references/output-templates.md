# 输出模板

本文件供技能在产出定位卡、四件套、运营计划、边界校验与可复制提示词时读取。
所有模板中的空格都留给用户自己去填。**不要替用户编造内容填进去。**

---

## 一、社群定位卡

```markdown
# 社群定位卡

## 一、适配判断
- 我为什么现在做社群：
- 我希望它解决的业务问题：
- 我已有的信任 / 用户 / 内容 / 合作资源：
- 我目前最大的限制：
- 如果现在不适合，替代方案是：

## 二、定位
- 服务的人：
- 他现在最具体的问题：
- 他为什么愿意留下（内容 / 关系 / 情绪，主供给：______）：
- 变现方式（1—2 个）：
- 持续供给能力：内容 ______ 条/周；一对一沟通 ______ 小时/周
- 前 100 个人从哪里来：
- 谁和我一起管（至少三个角色）：

## 三、定位一句话
这是一个帮 ______ 解决 ______ 的 ______ 社群，
用户进来能拿到 ______，
我通过 ______ 赚钱，
主要靠 ______ 留住人。

## 四、结构
- 社群类型：内容型 / 关系型 / 变现型 / 服务型 / 渠道型
- 是否需要分层：无 / 鱼塘→中转→核心
- 核心群门槛：
- 目标规模：
```

### 检查项

- [ ] 七个问题都能答上
- [ ] "服务的人"具体到能想象出画面（不是"想赚钱的人"）
- [ ] 变现方式先于活跃设计
- [ ] 定位一句话能顺畅说出口

## 二、四件套

### 2.1 社群名字

```text
备选一（垂直运营型 · 具体动作 + 人群）：
  名称：
  适合场景：

备选二（地域 + 领域）：
  名称：
  适合场景：

备选三（阶段 / 身份型）：
  名称：
  适合场景：
```

命名公式备查：

| 类型 | 公式 | 示例 |
|---|---|---|
| 垂直运营型 | 具体动作 + 用户画像 | 早起阅读打卡群、每天 5KM 打卡群 |
| 地域 + 领域 | 领域 + 城市 | XX 陪跑·北京 1 群 |
| 品牌 / 人名 + 领域 | 名称 + 领域 | XX 的 AI 变现圈 |
| 阶段 / 身份 | 期数或身份限定 | 第 3 期共读会、主理人闭门群 |

检查：

- [ ] 一看就知道做什么
- [ ] 电话里能一次介绍清楚
- [ ] 个人品牌未成型时，没有用个人名字做群名
- [ ] 无贬义、无谐音歧义

### 2.2 社群公告（200 字以内）

```text
【第一段 · 我们是谁】
欢迎来到【群名】。本群是【什么群】，主要聊【什么】。

【第二段 · 加入我们的好处】
在这里你能拿到：
1. 【具体的东西 1】
2. 【具体的东西 2】
3. 【具体的东西 3】
我们会定期做【什么活动】。

【第三段 · 谁在管 + 第一件事】
本群由【谁】和【谁】一起维护。
进群第一件事：改群名片，格式【地域-领域-昵称】。
有问题随时找【谁】。
```

检查：

- [ ] 好处具体、可见、能拿到
- [ ] 没有"干货满满""资源共享"这类空话
- [ ] 没有禁止事项（放在规则里）
- [ ] 没有做不到的承诺
- [ ] 200 字以内

### 2.3 社群运营规则

```text
【一、改群名片】
进群后请把群名片改成：【地域-行业/领域-昵称】
例：北京-AI教练-唐宋
原因：方便大家找到同城、同行、同频的人。

【二、鼓励分享】
1. 晒【什么】有奖：______
2. 邀请朋友进群有奖：______
3. 原创分享有奖：______

【三、这些事请不要做】
1. 不发与本群无关的广告（含软广）
2. 不刷屏、不连续发大量表情
3. 点对点的事私聊，不占用群公共空间
4. 涉及金钱、个人信息的要求，一律先找群主核实

【四、违规处理】
第一次：提醒并撤回
第二次：移出群，并在群内说明原因
```

快闪群（短期活动群）的极简版本：

```text
本群是为期【X 天】的【活动名】活动群。
活动期间会发【什么】，【几点】开始。
有疑问找【谁】。
```

检查：

- [ ] 先激励、后禁止
- [ ] 违规处理写明两级
- [ ] 运营者自己能做到所写的每一条
- [ ] 写完后读过一遍，用户能看懂

### 2.4 社群宣传海报文案

```text
【这是给谁的】
【人群 + 他现在最具体的状态】

【你能拿到什么】
1. ______
2. ______
3. ______

【为什么是我】
【你的相关经验 / 真实做过的交付 / 可核验的资质】

【时间与名额】
开始时间：______
名额：______

【怎么进来】
【具体动作：扫码 / 私信关键词 / 填表 / 支付】

【适合谁】______
【不适合谁】______
```

检查：

- [ ] 没有空话
- [ ] 好处具体、可见
- [ ] 没有做不到的承诺
- [ ] 时间、名额、加入方式齐全
- [ ] **每个数字都可追溯**（群人数、收入、成果、评价）
- [ ] 写清了适合谁和不适合谁

## 四、边界校验表

```markdown
# 边界校验结果

## 一、越界项（建议删除或改写）
| 位置 | 问题 | 风险 | 真实身份版本的替代做法 |
|---|---|---|---|

## 二、待确认项（需要你自己核实）
| 位置 | 需要确认什么 | 如果为真，需要保留什么证据 |
|---|---|---|

## 三、合规与隐私提醒
| 位置 | 风险类型 | 说明 |
|---|---|---|
```

检查清单：

1. 有没有设计"托""水军"或伪装成陌生用户的账号动作
2. 有没有编造群人数、收入、转化率、评价、聊天截图
3. 有没有承诺运营者无法交付的结果
4. 有没有搬运他人的话术、模板、清单而未标注来源
5. 有没有把未核实的信息写成既定事实
6. 有没有暴露成员隐私（姓名、头像、手机号、聊天记录、未授权数据）
7. 有没有平台与合规风险（诱导分享、虚假稀缺、绝对化用语、健康或收益承诺、类似多级分销的奖励结构）

单项判断标准：**这个动作，运营者能不能公开讲给成员听？**

## 五、可直接复制的提示词

### A. 定位七问（先做这一步）

```text
我要为我的业务做一个社群。请先不要给我方案，先用提问的方式帮我把定位梳理清楚。

每次只问一个问题，等我回答后再问下一个。依次问完这七件事：
1. 我为什么现在要做这个社群？它解决我哪个业务问题？
2. 这个社群服务谁？他现在最具体的一个问题是什么？
3. 我的社群靠什么赚钱？（付费会员 / 卖货 / 增值付费 / 资源对接 / 后端转化，选 1—2 个）
4. 我能不能持续供给？（每周内容条数、每周一对一沟通小时数、能不能定期制造可晒的东西）
5. 用户为什么愿意留下？（内容 / 关系 / 情绪，定一个主供给）
6. 前 100 个人从哪里来？
7. 谁和我一起管？（至少三个角色）

七个问题问完后，帮我把答案压成一句"定位一句话"，并列出我还答不上来的地方。

如果我的回答是模糊的（比如"想赚钱的人"），请追问让我写具体。不要替我编答案。
```

### B. 社群名字

```text
基于我的社群定位，帮我起社群名字。

请给三个备选，分别用不同的命名法：
1. 垂直运营型（具体动作 + 用户画像）
2. 地域 + 领域
3. 阶段 / 身份型

每个名字后面说明：适合什么场景、一看是否就知道这个群做什么、我在电话里能不能一次介绍清楚。

最后提醒我：如果我的个人品牌还没做起来，不要用我的名字做群名。
不要起带贬义、谐音、容易误解的名字。
```

### C. 社群公告

```text
帮我写一条社群公告，200 字以内。

必须包含三段，顺序不能变：
1. 我们是谁——本群是什么群、主要聊什么
2. 加入我们的好处——写出具体的、能拿到的东西（不能写"干货满满""资源共享"）
3. 谁在管 + 进群第一件事（改群名片，给出格式）

要求：不要一上来就写禁止事项；不要出现我做不到的承诺；不要写没发生过的成员成果；语气按我的表达习惯来。

写完单独列出"这一段里有哪些是我需要去核实的"。
```

### D. 社群运营规则

```text
帮我写一份社群运营规则，按三个方向组织：
1. 改群名片（给出固定格式，并说明为什么要改）
2. 激励分享（晒图有奖 / 邀请有奖 / 原创有奖，先给正反馈）
3. 禁止事宜（广告、刷屏、隐私提醒、涉及金钱的核实）

违规处理写两级：第一次提醒并撤回，第二次移出群并在群内说明原因。

要求：不能只有禁止；不要让用户看不懂；如果这是我的快闪群（短期活动群），另给一个极简版本。

最后提醒我：规则定完之后，我自己必须先做到。
```

### E. 社群宣传海报文案

```text
帮我写一段社群宣传海报文案，按五个问题组织：
1. 这是给谁的？2. 他能拿到什么？3. 为什么是我？4. 什么时候开始 / 有多少名额？5. 怎么进来？

要求：不出现"干货满满""资源丰富"这类空话；好处必须具体可见；不承诺我无法交付的结果；不写任何没有真实发生过的成员成果或数字；写清适合谁和不适合谁。

写完后用下面六条自检，并逐条告诉我是否通过：
□ 有没有空话 □ 好处是否具体 □ 有没有做不到的承诺
□ 时间名额加入方式是否齐全 □ 有没有编造的数字 □ 有没有写清适合与不适合的人
```

### F. 社群运营计划

```text
基于我的社群定位卡，帮我出一份社群运营计划，包含：
1. 分层与精力分配（鱼塘 15% / 中转 20% / 核心 65%）
2. 三大机制（规则、角色、活动）
3. 日常节奏时间表，并标注哪些可以自动化、哪些必须真人做
4. 用户分层维度
5. KOL 筛选提问与支持方式
6. 留存与续费：使用价值、社交价值、情绪价值各怎么给
7. 前两周启动清单（动作 / 负责人 / 截止时间 / 验收标准）

如果我的目标是"社群活跃"，请先确认我的变现方式是否清楚。
不要替我编造任何成员数据或成果。
```

### G. 边界校验

```text
请只检查我的社群方案有没有越界，不要重写：

1. 有没有设计"托""水军"或伪装成陌生用户的账号动作；
2. 有没有编造成员数、收入、转化率、评价、聊天截图；
3. 有没有承诺我无法交付的结果；
4. 有没有搬运他人的社群话术模板而未标注来源；
5. 有没有把我不确定的信息写成既定事实；
6. 有没有暴露成员隐私；
7. 有没有平台与合规风险（诱导分享、虚假稀缺、绝对化用语、收益承诺、类似多级分销的奖励结构）。

输出三栏：越界项 / 需要我确认的项 / 建议删掉的项。
每一条越界项都给一个"真实身份版本的替代做法"。
```
