# 三平台质量与平台表现标准

## 总验收闸门

每个内容单元都必须通过：

1. **业务任务**：能说清它在本周成交路径里负责哪一步。
2. **对象明确**：不是写给所有人，能让目标客户认出自己的处境。
3. **素材可追溯**：能指出来自内容母体、知识库或用户确认材料的哪一部分。
4. **判断具体**：有一个可以复述的核心判断，不是口号或正确废话。
5. **证据或场景**：至少有一个真实细节、案例、原话、动作或明确的观察边界。
6. **平台匹配**：符合这个平台的阅读/观看动作，没有简单复制。
7. **CTA真实**：行动入口真实存在，承诺的资料、服务和结果可交付。
8. **事实安全**：没有 AI 补出的经历、案例、数据、收入、价格、效果或客户隐私。
9. **表达可发布**：用户愿意用自己的名义发布，不只是在形式上“像文案”。

## 朋友圈

朋友圈是关系场景里的连续出现，不是缩短版公众号，也不是产品海报文字版。

推荐结构：

```text
具体场景/动作 → 一个观察或判断 → 对目标客户的关联 → 自然互动/行动
```

写作要求：

- 可以从一次答疑、见面、交付、业务动作或真实感受切入；
- 一条只讲一个主判断；
- 认知、关系和行动型内容要有节奏，不要每天都硬卖；
- 卖点集中，回答“为什么值得关注/购买、为什么现在、为什么找你、下一步怎么做”；
- CTA 要具体，例如回复关键词、提交情况、预约交流；只有真实存在的入口才能写。

常见 AI 味：泛泛感悟、过度完整的解释、每条都像广告、统一的金句结尾、整齐排比、没有生活动作。

## 公众号

公众号承担完整理解和信任建立，不是把朋友圈拉长。

推荐结构：

```text
真实场景/读者问题 → 表面问题 → 真正卡点 → 你的判断
→ 案例或证据 → 可执行路径 → 自然承接
```

写作要求：

- 一个文章先确定一个主任务：吸引注意、解释误区、建立信任、提供方法或承接咨询；
- 每个主要观点后面尽量跟解释、场景、证据或动作；
- 题目和首屏让目标读者知道“这篇解决什么问题”；
- 结尾回到客户下一步，不用万能升华；
- 文章长度、排版和配图按用户平台要求调整，不为了凑字数堆方法。

常见 AI 味：标题宏大、开头先定义概念、方法一二三平均用力、段落过度工整、没有作者判断和证据。

## 短视频口播

短视频承担即时理解、有效停留和进一步行动，不是公众号逐字稿。

推荐结构：

```text
具体问题/冲突/结果 → 一个核心判断 → 解释或案例
→ 一个可执行动作 → 与业务匹配的 CTA
```

写作要求：

- 尽快点名目标客户正在遇到的问题，不用长自我介绍；
- 开头既要有吸引力，也要筛选正确的人；
- 一条只讲一个主要判断；
- 抽象观点后面落到具体人物、行业、动作或结果；
- 长句拆成能说出口的节奏，但不要用口头禅伪装自然；
- CTA 优先引导高意向动作，如评论关键词、私信、领取资料、预约交流或了解产品。

常见 AI 味：概念定义开头、统一“今天分享三个方法”、每句话都像标题、全篇没有停顿、泛泛喊关注、为了钩子制造与业务无关的冲突。

## 去 AI 味的检查顺序

不要先改词。按以下顺序处理：

1. 删除没有来源的事实、案例和承诺；
2. 补回真实场景、客户语言和具体动作；
3. 把泛泛结论改成用户真正的判断或取舍；
4. 删除不必要的整齐排比、万能总结和过多小标题；
5. 按平台重组，不把同一篇内容复制三遍；
6. 朗读检查节奏，最后再处理个别词语。

## 平台表现与成交的关系

平台表现只优化“正确的人是否停留和继续理解”，不鼓励无关流量。评价时按内容目的记录：有效评论、私信、资料领取、咨询、报名、购买等；不要用点赞或播放量解释所有结果。
